# WanderLust

WanderLust is a full-stack travel accommodation web application inspired by Airbnb. Users can explore listings, create and manage their own properties, upload images, add reviews, and view locations on an interactive map.

## Live Demo
https://wanderlust-oo01.onrender.com/listings

## Features

- User Signup and Login
- Create, Edit and Delete Listings
- Upload Listing Images
- Add and Delete Reviews
- Interactive Map using Mapbox
- User Authentication and Authorization

## Tech Stack

- HTML
- CSS
- JavaScript
- EJS
- Bootstrap
- Node.js
- Express.js
- MongoDB
- Mongoose
- Mapbox
- Cloudinary
- Render

## Installation

Clone the repository:
```bash
git clone https://github.com/d-keerthi123/WanderLust.git

Navigate to the project directory:
cd WanderLust

Install the required dependencies:
npm install

Create a .env file in the root directory and add the required environment variables:
ATLASDB_URL=your_mongodb_connection_string
SECRET=your_secret_key
MAP_TOKEN=your_mapbox_token
CLOUD_NAME=your_cloudinary_name
CLOUD_API_KEY=your_cloudinary_api_key
CLOUD_API_SECRET=your_cloudinary_api_secret

Start the application:
node app.js

Open the application in your browser:
http://localhost:8080
