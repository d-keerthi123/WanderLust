# WanderLust

WanderLust is a full-stack travel accommodation web application inspired by Airbnb. Users can explore listings, create and manage their own properties, upload images, add reviews, and view locations on an interactive map.

## Features

- User Signup and Login
- Create, Edit and Delete Listings
- Upload Listing Images
- Add and Delete Reviews
- Interactive Map using Mapbox
- User Authentication and Authorization

## Tech Stack

- HTML
- CSS
- JavaScript
- EJS
- Bootstrap
- Node.js
- Express.js
- MongoDB
- Mongoose
- Mapbox
- Cloudinary
- Render
